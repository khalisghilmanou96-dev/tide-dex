# TideDex 🌊 — NOAA

Site statique GitHub Pages utilisant l'API publique NOAA CO-OPS.

Fonctions :
- niveaux d'eau des dernières 24 h ;
- prévisions haute/basse mer sur 48 h ;
- température de l'eau lorsqu'elle est disponible ;
- plusieurs grandes stations côtières NOAA ;
- unités métriques ;
- aucune clé API.

API : NOAA CO-OPS Data API.
